📅 Schedule System (LAN) — Полная документация
Клиент-серверная система управления расписанием учебного заведения.
Работает полностью оффлайн в пределах одной локальной сети.
Стек: Python 3.10+, FastAPI + SQLite (сервер), Tkinter (клиенты), fpdf2, requests, JWT.


🔹 Возможности
🔐 Авторизация и регистрация прямо в приложении (SHA-256 + JWT токены)
👥 Ролевая модель: admin, teacher, student
🔍 Умный автокомплит для всех полей (фильтрация по вводу)
⚠️ Проверка конфликтов перед добавлением занятия
📄 Экспорт расписания в PDF (кириллица, авто-перенос страниц)
🔔 Toast-уведомления об изменениях в расписании/событиях
⏳ Отсчёт дней до ближайшего события + пасхалка с Invoker
🌐 Архитектура LAN: один сервер, множество клиентов, автообновление каждые 30 сек
📁 Schedule_System/
 ├── 📄 server.py        # FastAPI сервер + SQLite + JWT + API эндпоинты
 ├── 📄 editor.py        # GUI редактора (авторизация, CRUD, PDF, уведомления)
 ├── 📄 viewer.py        # GUI просмотрщика (только чтение, автообновление)
 └── 📄 schedule.db      # База данных (создаётся автоматически при первом запуске сервера)
